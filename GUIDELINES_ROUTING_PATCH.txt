GUIDELINES ROUTING — REQUIRED CONNECTION

The reason the new Part 1 pages had no visible effect was routing.

The Dubai topic list must open the new Part 1 router.

In lib/guidelines.dart:

1. Add:
   import 'dubai_hse_topic_router.dart';

2. Find the existing Dubai topic builder.

3. Replace the Dubai branch with:

   builder: (_) => topic.guidelineCategory == GuidelineCategory.dubai
       ? DubaiHsePartRouter.pageFor(topic)
       : GuidelineDetailPage(topic: topic),

4. Do NOT call:
   DubaiHseTopicRouter.pageFor(topic)

5. Do NOT remove:
   dubai_hse_detail_page.dart
   because Topics 11–37 still use it as the fallback.

6. Do NOT create duplicate Dart filenames such as:
   *_FINAL.dart
   *_V2.dart
   *_UPLOAD_ONLY.dart

Part 1 routing:
1–5  -> DubaiHsePart1TopicPage
6–8  -> existing dedicated Scaffolding / Excavation / Lifting pages
9–10 -> DubaiHsePart1TopicPage
11–37 -> existing DubaiHseDetailPage

The Lifting, Scaffolding and Excavation pages already use the required:
Main Topic -> Expandable Section -> small > chevron -> Advanced Learning
pattern.
